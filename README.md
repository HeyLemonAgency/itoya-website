# Itoya — « Sous les fleurs »

A redesign proposal for **Itoya, restaurant japonais à Crissier**: a Next.js site built from the restaurant's real menu, formulas, practical information and photography.

```bash
npm install
npm run dev        # http://localhost:3000
```

| Route          | What it is                                                                                                                                   |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `/`            | Homepage: cinematic opening under the blossom canopy, a menu selection, the lunch and evening formulas, the room, and the booking invitation |
| `/la-carte`    | The full menu (166 dishes) with categories and search                                                                                        |
| `/formules`    | The lunch and evening tasting menus, their rules and supplements                                                                             |
| `/le-lieu`     | The room, the private rooms and the gallery                                                                                                  |
| `/contact`     | Hours, address, access and contact                                                                                                           |
| `/reservation` | The telephone-first booking journey                                                                                                          |
